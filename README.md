# PCL compiler written in OCaml 

###  Dynamic repo - updates keep coming

### Structure
let structure   =  
    let root    =     "pcl-compiler/"      in  
    let lib     =     root ^ "lib/"        in  
    let bin     =     root ^ "bin/"        in  
    let pcl     =     root ^ "pcl/"        in  
    let _build  =     root ^ "_build/"     in  
    (lib, bin, pcl, _build)  
    
(*

- "_build" folder generated by dune - DO NOT EDIT
- "bin" folder is executable entry point
- "lib" folder contains all the files I will create during my work on this project
- "pcl" folder contains pcl programs for testing
- "dune-project" is a file needed only in the root folder of the project
  
*)

### Run the compiler
- Build: `dune build`
- Print LLVM IR: `dune exec ./bin/main.exe -- ./pcl/programs/hello.pcl`
- Write LLVM IR: `dune exec ./bin/main.exe -- -o /tmp/hello.ll ./pcl/programs/hello.pcl`
- Build a native executable: `clang /tmp/hello.ll runtime/pcl_runtime.c -lm -o /tmp/hello`
- Run it: `/tmp/hello`
- Clean generated Dune files: `dune clean`
